# Aquino HUMCOM1 Final Project

This repository contains the final project for my Human Computer Interaction course. It is a personal portfolio website designed to showcase my work and demonstrate the design principles learned throughout the semester.

## Project Overview

The main goal of this project is to apply HCI concepts to web design. The website serves as a digital resume and a creative space, featuring a responsive layout and personal reflections.

## Repository Structure

* `aquino-HUMCOM1-final-project.html`: The main entry point of the website.
* `style.css`: Contains all the styling rules (Flexbox/Grid).
* `projects/`: Folder containing my project showcases.
* `Lab/`: specific laboratory exercises from the course.
* `Walls/`: Background images and assets (e.g., Asian village theme).
* `handwritten/`: Custom assets or handwritten notes digitized for the site.
* `profile.jpg`: Personal profile picture used in the bio section.

## Technologies Used

* **HTML** for structure.
* **CSS** for styling.
* **Git/GitHub** for version control.

## Installation and Setup

To view this project locally:

1.  **Clone the repository**
    ```bash
    git clone git@github.com:Eddie02345/Aquino-HUMCOM1-final-project.git
    ```

2.  **Navigate to the folder**
    ```bash
    cd Aquino-HUMCOM1-final-project
    ```

3.  **Launch the website**
    Open `aquino-HUMCOM1-final-project.html` in your web browser.
